# Contributing to AdaptiveShade

Thank you for helping improve AdaptiveShade. Source packaging is in progress; documentation, issue reports, and design feedback are welcome now. Build and installation instructions will be added alongside the source release.

## Report a bug

Include the Home Assistant version, browser or Companion app version, device model, viewport dimensions, and light/dark mode. Describe the steps, expected result, and actual result. Distinguish physical-device testing from browser emulation. Redact credentials, camera URLs, addresses, and private household details from logs and screenshots.

## Propose a change

Discuss substantial changes in an issue before implementation. Keep pull requests focused and explain the problem, changed behavior, and validation. Use placeholder entities and keep personal deployment files out of the repository.

For interface changes, consider touch, mouse, keyboard, visible focus, reduced motion, unavailable entities, and both palettes. Preserve other device layouts when making a device-specific change. Test controls with mocked device operations; do not operate real locks, garage doors, lights, or thermostats without explicit owner authorization.

## Submit a pull request

Fork the repository, create a branch, and open a pull request against the default branch. Include screenshots when useful, with private information removed. Report exactly what was tested and any limitations. Maintainers review changes before merging.

Be respectful and constructive. Contributions must preserve third-party notices and be compatible with the project's MIT licensing for original code.
